Pubblicazione & Condivisione Web

Come condividere questa Dashboard con colleghi e collaboratori

🚀 Opzioni di distribuzione:

  • Rete Locale Aziendale (Wi-Fi / LAN):

    Qualsiasi dispositivo (computer, tablet o smartphone) connesso alla stessa rete può accedere digitando l'indirizzo IP del tuo computer (es. http://192.168.1.XX:8080).

  • Server Web Cloud (Render, Railway, VPS, Docker):

    L'applicazione è completamente autonoma e contiene sia il server backend Python (con API REST) che il frontend HTML5/JS moderno, pronta per essere caricata su qualsiasi hosting cloud.

  • Collegamento Diretto al Database Excel:

    Tutti i dati provengono direttamente dal foglio Mappe.xlsx. Non appena aggiorni il file Excel, la dashboard si aggiorna all'istante.
